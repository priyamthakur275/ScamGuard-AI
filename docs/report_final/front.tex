\chapter*{\centering Abstract}
In India a text message is still the cheapest way to reach someone's phone, and fraudsters use it heavily. Their messages copy bank KYC reminders, electricity disconnection warnings, parcel updates and job offers, and more and more of them are written in Hindi or in a Hindi--English mix. ScamGuard is an AI-based system that reads one such message, decides whether it is a scam or genuine, points to the phrases behind that decision and suggests the user's next step.

The detector learns from ScamGuard-IN-2026, a set of 11,399 Indian messages that we assembled from public smishing reports, real Indian SMS, 2025--26 advisory texts and synthetic messages that are used only for training. We did not trust the report labels blindly: after checking them, 19.5\% of the reports we kept turned out to be genuine bank alerts, OTP messages or advertisements. Near-copies of the same campaign were grouped with MinHash so that a campaign never sits on both sides of the split. Logistic regression over word and character TF-IDF, joined with 31 readable intent patterns, scores 97.1\% accuracy and 3.2\% false alarms on 1,874 real messages from campaigns it never saw. Trained on the raw report labels instead, the same model raises false alarms to 34.0\%.

Our guide proposed a further question as the advancement of the project: does a spam filter built on one region's messages still work on another's, and how much local data repairs it? We trained Multinomial Naive Bayes and Logistic Regression on the UK-based UCI SMS Spam Collection and ran them unchanged on an Indian SMS dataset. Logistic Regression dropped from a spam F1 of 0.911 to 0.678 and let through roughly half of the Indian spam. With only 10\% of a labelled Indian pool (143 messages) added to training, the mean Indian F1 over three seeds rose from 0.681 to 0.964 while UK performance stayed the same. The improvement appeared in every seed, passed McNemar's test and remained when near-duplicate messages were kept apart. ScamGuard runs as a live web application (Next.js, FastAPI, PostgreSQL) with its own cross-domain page and a Streamlit demo, and the repository regenerates every figure in this report.

\vspace{0.4cm}\noindent\textbf{Keywords:} scam detection, SMS spam, smishing, domain shift, domain adaptation, TF-IDF, logistic regression, Naive Bayes, label noise, data leakage
