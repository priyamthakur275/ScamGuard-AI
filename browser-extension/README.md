# ScamGuard browser extension (Chrome / Edge / Brave)

Right-click selected text or a link → **Check with ScamGuard**. The toolbar
popup checks any pasted message. Uses the public no-login quick check, so
nothing is saved.

## Install (developer mode)
1. Download `scamguard-extension.zip` from the ScamGuard site (/extension) and unzip it.
2. Open `chrome://extensions` (or `edge://extensions`), turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder.
